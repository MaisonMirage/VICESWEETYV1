Analyse des 7 références visuelles

1. Le diner neon rose — Bar rétro avec lumière rose sous le comptoir, néon bleu au plafond, damier au sol. → Ce que le site doit capturer : le GLOW rose qui illumine par en dessous, le contraste rose × bleu, l'ambiance "nuit qui commence".

2. L'affiche Miami turquoise × pink — Palmier rose sur fond turquoise, rayures diagonales. → La combinaison turquoise/pink en aplats bold. Le site utilise ces couleurs mais pas assez en mode "graphique pop". Les statements devraient avoir cette énergie.

3. Le sunset synthwave — Gradient purple→pink→orange avec grille perspective, palmiers en silhouette, étoiles. → C'EST LE GRADIENT DU SITE. Le fond des sections dark devrait être CE dégradé, pas un deep-purple plat. Ajouter un subtle grid synthwave en perspective dans le CTA ou le footer.

4. Le soleil rétro rayé — Cercle avec gradient horizontal (bleu→violet→pink→orange→jaune), lignes horizontales. → Cet élément pourrait devenir un séparateur graphique entre sections ou un élément décoratif dans le footer. Un "sunset circle" en CSS pur.

5. L'illustration Vice City — Voiture rose, buildings Art Déco, neon signs, palmiers, ciel sunset. → L'ATMOSPHÈRE. Le site doit sentir cette chaleur de nuit d'été. Pas littéralement une illustration, mais l'éclairage, les couleurs, le mood.

6. Le moodboard 80's — Collage Instagram : vestes oversize, lunettes aviator, flamant neon, voiture vintage, paillettes. → L'ÉNERGIE. Fun, coloré, excessif assumé, "trop c'est pas assez". Le site est trop sage par rapport à cette énergie.

7. La typo striped "Miami Vibe" — Lettres avec rayures horizontales, turquoise et pink. → Possible de créer un effet CSS similaire sur un titre clé (gradient clip-text avec background repeating-linear-gradient). Idéal pour le statement "Too pretty to eat."

1. Identité de marque — 6.5/10

L'ADN Vice Sweety selon l'inspiration

Le logo neon script rose = pur Miami Vice 80's. C'est une pépite. Mais le site ne capitalise pas assez dessus. Le logo dit "nuit, neon, fête, vice assumé" — le site dit "pâtisserie clean". Il y a un décalage entre la promesse du logo et l'expérience du site.

La cible femmes + summer Miami 80's = pink neon, sunset gradients, tropical, aspirationnel mais accessible, Instagram-worthy, "guilty pleasure" assumé.

P0 Le neon glow du logo n'est pas exploité dans le design system

Le logo a un glow rose parfait. Mais le site utilise des couleurs plates. Aucun effet neon, aucun glow, aucune lumière. Le design system ne reflète pas l'énergie "neon night" du logo.

→ FIX : Ajouter des glows CSS (box-shadow, text-shadow rose/turquoise) sur les éléments clés. Les titres des statements devraient avoir un subtle neon glow. Les boutons CTA devraient pulser subtilement. Le fond deep-purple des sections devrait avoir des halos de lumière rose/turquoise.

P0 Pas de gradient sunset — le code signature du Miami 80's

Le Miami 80's c'est LE gradient sunset : rose → orange → violet. Actuellement le site a des fonds plats (cream, deep-purple, sky, blush). Aucun gradient qui dit "sunset".

→ FIX : Le CTA section (deep-purple) devrait avoir un gradient radial subtil rose→violet. Les sections statements devraient avoir des dégradés plus vibrants. Ajouter un gradient sunset dans le footer ou la section Notre Vice.

P1 Le flamant/palmier en pattern est trop discret

Les assets palmier_flamant.svg existent mais sont à 2.5% d'opacité dans le footer et hidden dans la nav. C'est le symbole Miami par excellence — il devrait être plus présent.

→ FIX : Augmenter l'opacité du pattern à 4-5% dans le footer. Ajouter un palmier ou flamant en SVG décoratif (position absolute) dans la section CTA ou Notre Vice. Peut-être un flamant en grand à côté du texte hero sur desktop.

P2 La typographie manque de personnalité "fun"

Abril Fatface pour les titres = élégant mais sérieux. Space Grotesk pour le body = propre mais neutre. JetBrains Mono pour les tags = technique. Aucune typo ne dit "summer, fun, playful". Pour attirer des femmes sur un concept dessert, il faut un peu plus de personnalité.

→ FIX : Garder Abril Fatface pour les gros titres (il a le côté display dramatique). Mais ajouter une touche italique sur les "accent phrases" (comme "Vice Sweety, c'est le vice assumé."). Utiliser le style italic/bold de Space Grotesk pour créer du contraste dans le copy.

2. Hero / First Impression — 7/10

P0 Le hero est statique — pas de "moment"

Les sites award-winner ont un hero qui raconte une micro-histoire en 3 secondes. Actuellement : texte apparaît, image apparaît, flèche apparaît. C'est propre mais pas mémorable. Tema's Cake marche parce que chaque vidéo a un "reveal moment" — le site doit avoir le sien.

→ FIX : Créer un "reveal sequence" au chargement : le fond commence légèrement plus sombre, un light sweep horizontal balaye l'écran (comme un reflet sur du verre), puis les trompe-l'œil apparaissent. Le titre pourrait avoir un effet de "typing" ou de "dévoilement" lettre par lettre pour le mot "vrais" seulement.

P1 Pas de gradient de lumière dans le hero

Le hero a un fond cream plat. Les sites premium ont toujours un jeu de lumière subtil — un spot, un gradient radial, quelque chose qui dit "éclairage cinématique".

→ FIX : Ajouter un radial-gradient très subtil au centre du hero (un halo blanc/rosé à 50% opacité) qui donne l'impression d'un spot de lumière éclairant les desserts depuis le haut.

P1 Le sous-titre manque de hiérarchie émotionnelle

"Trompe-l'œil, smoothies, cookies — faits main avec obsession à Marseille." C'est informatif, pas émotionnel. La première impression devrait créer du désir, pas lister des produits.

→ FIX : Remplacer par quelque chose de plus sensoriel : "Tu ne devineras jamais que c'est un gâteau." ou "L'illusion parfaite. Le goût en plus." — puis lister les produits plus bas dans l'intro band.

P2 Pas de vidéo ou micro-animation sur les desserts

Tema's Cake est 100% vidéo-first. Le site statique peut compenser avec des micro-interactions : un léger "float" sur l'image hero, un subtle parallax plus prononcé, ou une rotation très lente.

→ FIX : Ajouter un très léger CSS float animation (2px up/down en 4s) sur le hero-img quand il n'y a pas de scroll, en plus du parallax existant. Ça donne vie à l'image.

3. Direction artistique — 6/10

C'est le point le plus faible. Le site est "propre" mais pas "léché". Il manque cette couche de direction artistique qui transforme une page web en expérience de marque.

P0INSPO Pas de section "unboxing / reveal" — LE concept manquant

Tema's Cake cartonne grâce au moment de reveal : on ouvre la boîte, on coupe le fruit, et l'intérieur est un gâteau. Le site n'a AUCUNE section dédiée à ce moment magique. C'est comme vendre de la magie sans montrer le tour.

→ FIX MAJEUR : Créer une section "Le Reveal" entre l'intro band et Notre Vice. Concept : une image d'un trompe-l'œil entier à gauche, une image du même coupé en deux à droite, avec un slider interactif ou une animation au scroll qui "coupe" le fruit. Texte : "Tu coupes... et la magie opère." C'est LA section qui va convertir.

P0 Les sections manquent de profondeur visuelle

Chaque section est un bloc plat avec un fond uni. Les sites award-winner ont des couches : fond + pattern + grain/noise + lumière + contenu. Ça crée de la profondeur et du luxe.

→ FIX : Ajouter un CSS noise/grain overlay très léger (1-2% opacité) sur les sections dark. Ajouter des "light orbs" flottants (cercles flous roses/turquoise en position absolute) dans la section CTA et Notre Vice. Ajouter un subtle gradient mesh dans les statements.

P0 Pas de curseur personnalisé — détail award-winner

Les sites Awwwards ont quasi systématiquement un curseur custom. Même subtil, ça montre un niveau de soin extrême.

→ FIX : Curseur custom petit cercle rose (mix-blend-mode: difference) qui grossit au hover sur les éléments cliquables. Pas obligatoire mais très impactant pour un jury award-winner.

P1 Les photos de catégories n'ont pas de traitement uniforme

Les cat-blocks utilisent les photos telles quelles avec juste un overlay gradient. Les sites premium appliquent un color grading uniforme (même tonalité, même chaleur) sur toutes les photos pour créer une cohérence visuelle.

→ FIX : Appliquer un filtre CSS uniforme sur toutes les cat-block img : brightness(1.05) saturate(1.1) — pour réchauffer légèrement et uniformiser. Ou mieux : reprocesser les images avec un LUT Miami sunset.

P1INSPO Pas de mise en avant du packaging

Le packaging doc montre un travail énorme sur les boîtes (La Galerie, L'Écrin, L'Arche...). Tema's Cake montre que le packaging EST le produit sur les réseaux. Le site ne montre AUCUNE boîte.

→ FIX : Quand les visuels packaging seront prêts, créer une section "L'Écrin" dédiée avec les boîtes. En attendant, le texte dans Notre Vice pourrait mentionner le packaging.

4. Copywriting — 8/10

Le copy est bon. "Trop beaux pour être vrais", "Too pretty to eat", "le vice assumé" — ça marche. Quelques ajustements :

P1 Le ton est encore trop "artisan" et pas assez "lifestyle"

Pour attirer les femmes avec la vibe Miami, le copy devrait être plus lifestyle, plus "guilty pleasure", plus aspirationnel. Moins "fait main avec obsession", plus "ton nouveau vice".

→ FIX exemples : "Tes yeux disent fruit. Ta bouche dit gâteau." / "Le dessert que tu vas poster avant de goûter." / "Addictif. Photogénique. Marseillais."

P2 Les descriptions catégories sont génériques

"Sunset dans un verre" c'est bien. "Fondants, chocolatés, addictifs" c'est générique. Chaque catégorie devrait avoir une personnalité propre.

→ FIX : Réécrire chaque cat-sub avec plus de sensorialité et de personnalité. Smoothies → "Mangue, passion, un coucher de soleil par gorgée." Cookies → "Fondant dedans. Croustillant dehors. Game over."

5. Layout & Rythme — 7.5/10

P1 La page est trop linéaire — manque de ruptures

Le flow est : hero → intro band (cream) → notre vice (dark) → 2 blocs → statement → full-width → 2 blocs → statement → 2 blocs → CTA → insta → visit → footer. C'est bien structuré mais prévisible. Les award-winners surprennent le scroll.

→ FIX : Ajouter la section "reveal/unboxing" comme rupture. Ajouter un compteur/chiffre marquant quelque part ("1200+ trompe-l'œil vendus ce mois" style counter animated). Varier la largeur des sections (certaines avec max-width étroite pour du texte centré dramatique).

P2 La section Instagram pourrait être plus immersive

Actuellement c'est une grille 4x1 basique. Pour une marque visuelle comme Vice Sweety, cette section devrait être un "moodboard" vivant.

→ FIX : Transformer en carrousel horizontal infini (marquee CSS) avec des photos de tailles variées. Ou au minimum, passer à une grille masonry-style. Ajouter un hover qui montre les likes.

6. Animations — 7.5/10

Les animations cinématiques ajoutées (parallax hero, staggered reveals, scale statements) sont un bon début. Mais :

P1 Pas de smooth scroll avec easing personnalisé

Le site utilise scroll-behavior:smooth natif. Les sites premium ont un smooth scroll custom avec Lenis ou locomotive-scroll qui donne cette sensation de "glide" ultra-fluide.

→ FIX : Intégrer Lenis (lightweight, 3KB) pour un smooth scroll buttery. C'est LE détail qui fait "award-winner" immédiatement.

P1 Les transitions de section sont abruptes

On passe de cream → deep-purple → cream sans transition. Les sites premium ont des transitions de couleur plus douces.

→ FIX : Ajouter des separators visuels entre les sections : un SVG wave, un dégradé de 60px, ou un divider graphique avec le pattern palmier. C'est un détail qui adoucit tout le scroll.

P2 Les cat-blocks hover est basique (scale 1.04)

Le zoom léger sur hover est OK. Mais on peut aller plus loin : overlay qui se clarifie, texte qui monte, un arrow ou "Voir" qui apparaît.

→ FIX : Au hover, le cat-sub slide up de 5px, et un petit arrow "→" apparaît en fade. Ça crée de l'affordance et du mouvement.

7. Mobile — 7.5/10

P1 Le hero mobile ne montre pas assez le produit

Sur mobile (90vh), avec le texte en haut et l'image en bas, l'image hero risque d'être petite ou tronquée. Sur TikTok/Instagram (le canal principal de la cible), les utilisatrices scrollent en vertical — le hero mobile est PLUS important que le desktop.

→ FIX : Sur mobile, passer à un layout vertical : titre en haut (plus petit), image centrée grande (60% de la hauteur), sub en dessous. L'image doit dominer.

P2 Le mobile menu pourrait avoir plus de personnalité

Le menu mobile est fonctionnel mais sobre (texte blanc sur dark gradient). Pour la cible femmes Miami, on peut ajouter du glow, du rose, du fun.

→ FIX : Ajouter un neon glow rose sur les liens du mobile menu au hover/tap. Ajouter le logo au centre du menu. Ajouter un subtle gradient animé en arrière-plan.

8. Technique & Performance — 8.5/10

La technique est solide : Schema.org, OG tags, srcset, preload, WCAG, prefers-reduced-motion. Points restants :

P2 Pas de preload pour la font display (Abril Fatface)

La font du titre hero est chargée via Google Fonts mais sans preload font file. Ça peut causer un FOUT visible sur le H1.

→ FIX : Ajouter un font-display: swap est déjà géré par Google Fonts, mais ajouter un preload pour le fichier woff2 d'Abril Fatface si possible.

P3 Le logo est un PNG de 762KB

Le logo Vice_Sweety_Logo.png fait 762KB. C'est lourd pour un asset nav/footer qui se charge immédiatement.

→ FIX : Convertir en WebP (devrait descendre à ~50KB) ou mieux, en SVG si possible. En attendant, au minimum redimensionner (le PNG actuel est probablement surdimensionné).

9. Moment viral / Unboxing — 4/10 ⚠️

C'est le point le plus critique. C'est aussi la plus grosse opportunité.

Leçons de Tema's Cake

Les 10 screenshots TikTok montrent la recette du succès viral :

  • La box train (399.8K likes) — le format WOW, spectaculaire, filmable
  • L'unboxing en voiture — moment intime de découverte, réaction spontanée
  • La mini box architecturale (148.8K likes) — packaging = objet d'art, les gens filment AVANT de manger
  • Le tea time 3-tier — mise en scène luxe accessible, "je le mérite"
  • Le packaging aquarelle rose — féminin, photogénique, "je pose ça sur ma story"
  • Le moment coupe — on ne sait pas ce qu'il y a dedans → SURPRISE

Le site doit CAPTURER ces moments et les transformer en sections web.

P0NEW Créer une section "Le Reveal" avec effet avant/après

L'atout n°1 du trompe-l'œil c'est la SURPRISE quand on coupe. Le site ne montre jamais ce moment. Un slider avant/après (fruit entier → fruit coupé) serait viral en soi.

→ FIX : Section avec un slider drag ou scroll-triggered. Image du citron entier qui se "coupe" pour révéler l'intérieur gâteau. Texte dramatique. C'est la section hero bis.

P0NEW Intégrer des vidéos TikTok/Instagram

Tema's Cake a 399K likes sur UN TikTok. Le contenu vidéo est ROI pour cette cible. La section Instagram actuelle montre des photos statiques. Il faut de la vidéo.

→ FIX : Remplacer ou compléter la section Instagram avec 2-3 embeds TikTok/Reels des meilleurs moments (unboxing, coupe, réactions). Ou au minimum, une section vidéo hero-width avec un autoplay muet d'une compilation de 10 secondes.

P1INSPO Pas de "social proof" visuel

Tema's Cake montre 399K likes, 28.3K partages. Vice Sweety ne montre aucun chiffre, aucun avis, aucune preuve sociale. Les femmes achètent sur la recommandation et la validation sociale.

→ FIX : Ajouter une bande de "social proof" : logos réseaux + chiffres ("2K+ followers" même modeste), ou des mini-témoignages clients, ou des screenshots d'avis Google. Même 3 avis bien choisis changent tout.

10. Univers immersif — 5/10

P0 Le site ne "sent" pas Marseille

Vice Sweety c'est Marseille + Miami. Actuellement le site pourrait être de n'importe quelle ville. L'adresse est écrite mais l'univers visuel ne dit pas "sud, soleil, mer, terrasse".

→ FIX : Intégrer des éléments visuels marseillais subtils : une photo de la boutique avec la lumière méditerranéenne, une référence au Vieux-Port, un bleu mer dans la palette. Le palmier/flamant aide mais il faut aussi de la chaleur humaine.

P0 Pas de "monde" Vice Sweety — juste un menu

Les marques award-winner créent un univers : Tema's Cake c'est "la créatrice passionnée qui prépare devant toi". Vice Sweety n'a pas de personnage, pas d'histoire visuelle, pas de récit émotionnel au-delà du texte.

→ FIX : La section Notre Vice est un bon début mais elle a besoin d'une photo HUMAINE plus forte. Les gens connectent avec des visages. Une photo de l'équipe souriante, en train de créer, avec de la lumière chaude. Montrer les mains qui sculptent un trompe-l'œil.

P1NEW Pas de "signature sonore" ou d'interaction sensorielle

Les sites premium de food ont souvent un petit son au hover ou au scroll, ou un effet haptique (vibration mobile). C'est un extra, mais pour un award, ça compte.

→ FIX : Ajouter un son de "couteau qui coupe" ultra-court (100ms) au click sur le slider reveal. Optionnel mais mémorable.

Mémo Brand — À garder en tête

Le positionnement unique de Vice Sweety

Vice Sweety n'est PAS Tema's Cake. Tema's = populaire, girly, rose aquarelle, Paris banlieue. Vice Sweety = Miami neon, summer, Marseille soleil, luxe fun.

Le logo script neon rose est l'ADN. Tout doit en découler : glow, lumière, nuit d'été, coucher de soleil, neon signs, plage, vice, addiction, plaisir assumé.

La cible : femmes 18-35, Instagram-native, qui veulent poster avant de manger, qui cherchent l'expérience autant que le goût. Le "je mérite ce plaisir". Le "c'est trop beau je peux pas le manger".

Le ton : complice, sensuel sans être vulgaire, un peu provocateur ("vice assumé"), jamais scolaire. Tutoiement. Phrases courtes. Impact.

Les mots-clés visuels : neon glow, sunset gradient, palm trees, flamingo, tropical night, Miami Vice (la série), 80's typography, hot pink × turquoise, deep purple night sky.

Règles design issues du dossier Miami 80's

Ces règles découlent directement des 7 images d'inspiration + la palette RTF :

  • Règle 1 — Le gradient sunset est OBLIGATOIRE : au moins une section du site doit avoir le gradient purple→magenta→coral→or. C'est décrit comme "la vitrine néon au milieu du blanc". La section CTA ou Notre Vice est le candidat idéal.
  • Règle 2 — Le neon glow est l'identité : chaque élément important (titre, CTA, séparateur) doit avoir un glow rose ou turquoise. C'est ce qui différencie Vice Sweety de toute autre pâtisserie.
  • Règle 3 — Le fond clair devient lavande-blush : passer de #FFFAF6 (cream tiède) à #FEFCFF ou #F8F4FA (blanc rosé Art Déco). Ça aligne le fond avec l'ADN Miami sans tout casser.
  • Règle 4 — Le pink #e63b7a remplace #FF69B4 : plus chaud, plus profond, plus "neon sign" que "bonbon". C'est le pink de Vice City.
  • Règle 5 — Le teal #0BBFBF remplace #40E0D0 : plus piscine Art Déco, moins menthe. Plus de personnalité.
  • Règle 6 — Le synthwave grid : un élément de grille en perspective (lignes qui convergent vers l'horizon) dans au moins une section dark. Très subtil (3-5% opacité) mais il ancre tout dans le 80's.
  • Règle 7 — Les palmiers sortent de l'ombre : le pattern palmier/flamant doit être plus visible. En silhouette sur le sunset, en SVG décoratif, ou en fond de section avec plus d'opacité.
  • Règle 8 — Au moins 1 titre avec effet retro : gradient clip, rayures, ou outline stroke — inspiré de la typo "Miami Vibe" striped.
