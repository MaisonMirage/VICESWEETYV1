Première impression · 3 secondes pour convaincre
WinLe trio litchi-fraise-framboise est magnifique
Trois textures différentes (écailles, miroir, drupéoles), même rouge, fond crème — c'est éditorial, minimal, premium. Le passage du gradient criard au fond crème avec photo produit est un upgrade massif.
FixLe titre utilise --deep mais cette variable n'existe pas
Dans le CSS, color: var(--deep) n'est pas défini dans le :root — le texte du hero est probablement invisible ou par défaut. Il faut var(--deep-purple) ou var(--text).
→ Bug critique : le hero title est potentiellement invisible. À corriger immédiatement.
FixLe bouton CTA utilise aussi var(--deep)
Même problème pour .btn-hero — background et border pointent vers une variable inexistante.
→ Remplacer par var(--deep-purple) partout.
FixLe scroll indicator SVG est encore en stroke="#fff" (blanc)
Le SVG du chevron dans le HTML est codé en dur en blanc alors que le hero a maintenant un fond crème. Il sera invisible.
→ Changer stroke="#fff" en stroke="currentColor" pour hériter du CSS.
FixResponsive mobile : margin-top écrase le contenu
Le hero-content a margin-top:15vh, mais sur mobile (max-width:900px) il passe à -3vh et sur 500px à 0. La transition est brutale. Avec le fond image en "contain", sur mobile les fruits deviennent minuscules.
→ Sur mobile, passer à background-size:cover avec position:center bottom, et réduire la taille de l'espace vide.
PomelliGénérer une version portrait (9:16) du trio pour mobile
Un hero qui marche sur desktop ET mobile nécessite deux images. La version mobile doit cadrer les fruits en plus gros, verticalement.
→ Prompt Pomelli pour un cadrage portrait rapproché + CSS art direction avec <picture> et media queries.

Identité Visuelle & Branding
Logo · Palette · Typographie · Packagings
WinLe logo script néon est parfait pour la marque
L'écriture cursive rose sur fond sombre = instantanément lisible, mémorisable, instagrammable. Le trait de soulignement ajoute du mouvement. C'est du branding solide.
WinLes packagings Pomelli sont au niveau award
Le sac cookie (noir + flamants roses), le pot cookie dough (transparent + palmiers), les gobelets smoothie/milkshake — tout est cohérent. Le pattern palmier/flamant fonctionne à toutes les échelles. C'est le genre de packaging qu'on photographie avant de consommer.
WinLa palette rose × turquoise × deep purple est distinctive
C'est une palette Miami Vice modernisée. Pas générique, pas déjà vue partout. Le deep purple (#1a0a2e) comme base sombre est un choix malin — plus sophistiqué qu'un noir pur.
FixLa typo display (Abril Fatface) fait "blog lifestyle", pas "dessert premium"
Abril Fatface est très utilisée dans le design food/lifestyle et commence à être datée. Pour une marque qui veut le positionnement ultra-premium de ses trompe-l'œil, une display plus unique serait un upgrade. Alternatives : Playfair Display pour le côté éditorial, ou une sans-serif condensée bold pour un look plus contemporain.
→ À considérer pour V2. Pas urgent mais c'est ce qui sépare un "beau site" d'un site award-winner.
FixQuatre polices Google Fonts = performance
Abril Fatface + Bebas Neue + Space Grotesk + JetBrains Mono = 4 familles chargées. Or, Bebas Neue n'est utilisé que pour .heading (jamais appelé dans le HTML visible). JetBrains Mono est utilisé uniquement pour des micro-éléments (boutons, labels).
→ Supprimer Bebas Neue (inutilisé). Considérer remplacer JetBrains Mono par Space Grotesk en weight 600 pour les labels.

La grille Instagram recycle smoothie-sunset-1, cookie-dough-2, pancakes-1, crepes-1. Sur un award-winner, cette section montrerait du contenu unique — style "behind the scenes", process de fabrication, clients, ambiance boutique.

UX & Architecture
Navigation · Flow · Conversion · Mobile
WinLa structure narrative est bonne
Hero (wow) → Intro (promesse) → Story (authenticité) → Catégories (produits) → Statements (personnalité) → CTA (conversion) → Instagram (social proof) → Visit (action). Le storytelling scroll est bien pensé.
AlerteTout renvoie vers menu.html — c'est un entonnoir aveugle
Chaque catégorie (smoothies, milkshakes, cookies, cookie dough, trompe-l'œil, pancakes, crêpes) renvoie vers la même page menu.html. L'utilisateur qui clique sur "Cookie Dough" s'attend à voir la cookie dough, pas une page menu générale. C'est frustrant.
→ Ajouter des ancres (menu.html#cookie-dough) ou mieux, des pages produit individuelles pour chaque catégorie. La page produit est le cœur de la conversion.
FixPas de navigation principale visible
La navbar n'a qu'un burger menu et un bouton "Commander". Pas de liens vers les catégories, pas de "Notre Histoire", pas de "Nous Trouver". Sur desktop, tu as 1400px de largeur et tu n'en utilises que 200px. C'est du gaspillage d'espace et de conversion.
→ Ajouter 3-4 liens texte dans la navbar desktop : Nos Créations · Notre Vice · Nous Trouver. Garder le burger pour mobile uniquement.
FixLe CTA "Prête à craquer ?" genré au féminin
Ça exclut 50% des clients potentiels. C'est un choix de positionnement possible, mais si ta cible est mixte, c'est un problème.
→ "Prêt(e) à craquer ?" ou reformuler : "Le plaisir n'attend pas." / "Impossible de résister."
FixL'adresse est un placeholder
"47 Rue de la République, 13002 Marseille" — si c'est pas la vraie adresse, c'est un problème SEO et de confiance. Google indexe ça.
→ Mettre la vraie adresse ou retirer la section si la boutique n'est pas encore ouverte.
FixZéro micro-interactions
Les hover states sont basiques (scale 1.04 sur les images, translateY sur les boutons). Un site award-winner a des interactions qui racontent l'histoire : cursor personnalisé, parallax subtil sur le hero, animation du logo au scroll, reveal staggeré sur la grille Instagram.
→ Phase 2 : ajouter du mouvement intentionnel. Le hero trio pourrait avoir un léger parallax (les fruits bougent plus lentement que le texte).

Copywriting
Ton · Personnalité · Persuasion
Win"Trop beaux pour être vrais" est une baseline parfaite
Ça résume tout en 5 mots : le trompe-l'œil, l'esthétique premium, la surprise. C'est mémorable et ça marche aussi bien en tagline qu'en hashtag.
WinLe tutoiement + "plaisir coupable" installe le ton
Le "tu coupes — et l'illusion se révèle" est une phrase qui crée une expérience. Le "Vice" du nom est bien exploité. La personnalité de marque est claire : complice, séductrice, sans culpabilité.
Fix"Welcome to the Sweet Side" — le franglais maladroit
Le titre de la section intro est 100% anglais alors que tout le reste est en français avec des touches d'anglais ponctuel ("Too pretty to eat", "Made with love"). Ce titre ne mérite pas d'être en anglais — il n'a pas l'impact d'un statement. Ça fait forcé.
→ Le remplacer par un titre français percutant : "L'art du trompe-l'œil" ou "Des créations qui se dévorent des yeux".
FixLes descriptions de catégories sont trop similaires
"... qui font fermer les yeux" revient 2 fois. "Le plaisir coupable" revient 2 fois. Les descriptions des catégories sont interchangeables — elles ne différencient pas les produits entre eux.
→ Réécrire chaque catégorie avec un angle unique : le smoothie = la couleur et le voyage, le cookie = la texture et l'addiction, le trompe-l'œil = l'illusion et la surprise.

Performance & Technique
Vitesse · SEO · Accessibilité · Code
WinSingle-file HTML = déploiement simple
Tout dans un seul fichier, pas de framework, pas de build step. Pour un site vitrine, c'est un bon choix pragmatique.
Alertehero-trio.webp fait 7281×4096 et ~500KB
L'image du hero est massive. Sur mobile, on charge 7000px de large pour un écran de 400px. C'est un gaspillage de bande passante qui impacte directement le LCP (Largest Contentful Paint) — le métrique n°1 de Google pour le SEO.
→ Générer 3 tailles (640w, 1280w, 2560w) + utiliser srcset et <picture> avec le format portrait mobile.
FixAucune image n'a de lazy loading
Toutes les images du site se chargent en même temps. Les images sous le fold (catégories, Instagram, etc.) devraient avoir loading="lazy".
→ Ajouter loading="lazy" sur toutes les images sauf le hero et le logo.
FixLes images de catégorie n'ont pas de dimensions définies
Pas de width/height sur les balises <img>. Ça cause du CLS (Cumulative Layout Shift) — les éléments bougent pendant le chargement. Google pénalise ça.
→ Ajouter width et height sur chaque <img> pour réserver l'espace.
FixPas d'Open Graph / Twitter Cards
Quand quelqu'un partage le lien sur Instagram, WhatsApp, ou iMessage, il n'y a pas d'image de preview, pas de description formatée. C'est du branding gratuit perdu.
→ Ajouter og:image (le trio hero), og:title, og:description dans le <head>.
FixPas de schema.org pour la boutique
Le site a des horaires, une adresse, un téléphone — mais pas de données structurées. Google ne peut pas les afficher dans les résultats de recherche (le rich snippet avec horaires, téléphone, note).
→ Ajouter un script JSON-LD type="LocalBusiness" avec les infos de la boutique.

Verdict Final
Vice Sweety a une identité de marque plus forte que 95% des food brands sur le marché. Le logo, la palette, les packagings Pomelli, le naming — tout ça c'est du A+. Le problème c'est que le site web ne traduit pas encore cette qualité. Le hero avec le trio est un grand pas en avant, mais il y a des bugs CSS qui rendent des éléments invisibles, des images à optimiser, et surtout il manque des images lifestyle uniques qui racontent l'histoire au-delà des produits packshot.

La bonne nouvelle : avec Pomelli, tout est possible. 4-5 sessions de génération bien ciblées (atelier, lifestyle Instagram, hero mobile, trompe-l'œil full-width) et le site passe de 6.8 à 8.5+. Les corrections CSS sont triviales — c'est quelques minutes de code. Le vrai travail c'est l'image.

Le site a le potentiel d'un Awwwards Honorable Mention dans sa version actuelle, et d'un Site of the Day avec les upgrades V2.
