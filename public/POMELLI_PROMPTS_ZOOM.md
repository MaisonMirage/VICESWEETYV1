# Pomelli Prompts — Vice Sweety Zoom Photos

## Style Guide (apply to ALL prompts)
- Square format 1024×1024
- Dark moody background matching website (#1a0825 to #2d1b3d range)
- Black reflective surface underneath (like polished obsidian or black marble)
- Neon pink/rose side lighting (Miami Vice aesthetic)
- Macro close-up style, ultra detailed textures
- Single dessert centered, no other objects
- Feminine luxury feel — think Dior, Charlotte Tilbury, Ladurée
- NO text, NO watermarks

## How to use in Pomelli

1. Upload the **reference image** listed for each prompt
2. Paste the prompt
3. Generate in **1024×1024** (square) for individual desserts
4. Generate in **landscape 16:9** for the lineup (#7)
5. Save as `.webp` and name them:
   - `citron-zoom.webp`
   - `passion-zoom.webp`
   - `fraise-zoom.webp`
   - `litchi-zoom.webp` (NEW — on n'en avait pas)
   - `peche-zoom.webp`
   - `mandarine-zoom.webp` (NEW — on n'en avait pas)
   - `trompeloeil-lineup-trans.webp` (si tu refais la lineup)
6. Drop them dans `img/` et le site les prend automatiquement

## Tips
- If the colors come out too bright, add: "dark and moody, low-key lighting"
- If the background isn't dark enough, add: "pure black background, very dark"
- If it doesn't look realistic enough, add: "photorealistic, shot on Canon EOS R5"
- If you want more pink neon, add: "strong neon magenta accent light"
- If the dessert doesn't match your real product, emphasize the reference image and add: "match the exact shape and texture of the reference image, only change the background and lighting"
